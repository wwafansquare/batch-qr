# batch-qr

印刷物用に、URL の帯と QR コードをまとめて出力します。元画像がある行はその画像へ重ね、ない行は帯と QR コードだけを出力します。

画像ありのとき、URL の帯は左下または右下、QR コードはどちらの指定でも元画像の右下です。下端に URL の帯、そのすぐ上の元画像の右端に QR コードを描きます。URL の文字が画像の幅に収まるときは、出力の幅も高さも入力と同じです。

```text
|-------|
|     QR|
|http://...|
|-------|
```

画像なしのとき、`left` は帯と QR コードを左へ、`right` は右へ寄せます。幅の差で空いた部分は透明です。

## 必要なもの

- Python 3
- PC にインストール済みのフォント `JFドットmilkjf16` (`config.py` の `FONT_FAMILY` で指定)
- 次のパッケージ

```text
python -m pip install -r requirements.txt
```

フォントファイルはこのフォルダには置きません。Windows に入っているフォントを名前で使います。

## フォルダ

- `img` : 元画像
- `list.csv` : どの画像に、どの URL を、どちらの角へ載せるか
- `dist` : 出力。実行すると作られます

`config.py` のパスは、このフォルダを基準にした相対パスです。

## 入力

`list.csv` はヘッダなしの UTF-8 です。1行が次の4列です。

```text
true|false,名前,URL,left|right
```

1列目が `true` の行は、2列目のファイル名を `img` から読んで重ねます。`false` の行は元画像を読まず、2列目の名前で `dist` に保存します。拡張子がなければ `.png` を付けます。

```text
true,wwa_island02_town.png,https://wwawing.com/wing/island02,right
true,wwa_caves01.png,https://wwawing.com/wing/caves01,left
false,tellersdungeon,http://yuym.web.fc2.com/wwas/tellex/,right
```

## 実行

このフォルダで次を実行します。

```text
python batch_qr.py
```

出力は PNG で、`dist` に保存します。画像ありの行は入力と同じファイル名です。画像なしの行は2列目の名前です。同名のファイルが既にある行は上書きせずスキップします。作り直すときは、そのファイルを `dist` から消してから再実行します。

列の過不足、画像の有無や配置の指定ミス、画像ありなのにファイルがない行はメッセージを出して次の行へ進みます。

## 配置

- URL 帯の高さは 35px、背景色は `#cc66cc`、文字サイズは 32px です。
- 帯の幅は文字幅に合わせます。短い URL は QR より細い帯になります。
- URL 帯は、指定した角の端に隙間なく接します。QR コードは配置に関わらず元画像の右端で、帯のすぐ上に隙間なく接します。
- URL 帯が画像幅より広いときだけ、キャンバスを広げます。広がった部分は透明です。`left` なら右側、`right` なら左側に足します。QR は元画像の右端に置き、この拡張部分には出しません。
- URL が幅に収まっているときは、QR が画像からはみ出してもキャンバスサイズは変えず、画像の範囲で切れます。

画像なしの行は、帯の高さに QR の高さを足したサイズです。帯と QR は指定した側に寄せ、もう一方に空いた部分は透明のままです。

```text
left                         right
|QR        |                 |        QR|
|http://...|                 |http://...|
```

## 設定

色、文字サイズ、帯の高さ、QR の大きさは `config.py` の定数で変えます。

QR の一辺のピクセル数は `(モジュール数 + QR_BORDER * 2) * QR_BOX_SIZE` です。URL が長いほどモジュール数が増え、QR も大きくなります。初期値の `QR_BOX_SIZE = 4` では、数十文字の URL でおよそ 120px になります。`QR_BORDER` を上げると、QR の周囲に白い余白が付きます。
