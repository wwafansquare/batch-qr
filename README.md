# batch-qr

印刷物用に、URL の帯と QR コードをまとめて出力します。元画像がある行はその画像へ重ね、ない行は帯と QR コードだけを出力します。

URL は幅の中で折り返します。画像ありのときは画像の幅です。画像なしのときは `config.py` の `URL_WRAP_WIDTH` から QR コードの幅を引いた残りです。1行に収まるときは帯を文字幅にします。折り返したときはその幅いっぱいに帯を広げ、文字がない部分も帯の背景色で塗ります。画像なしで折り返した出力の幅は `URL_WRAP_WIDTH` です。

画像ありのとき、1行の帯は左下、折り返した帯は下端いっぱいです。文字は左に寄せます。QR コードは元画像の右下、帯のすぐ上です。出力の幅は元画像と同じです。

```text
|-------|
|     QR|
|http://...|
|.........|
|-------|
```

画像なしのとき、URL の帯は QR コードの左隣に置き、下端を揃えます。文字は左に寄せます。帯にも QR にも掛からない部分は透明です。

```text
|        QR|
|http:// QR|
|......  QR|
```

## 必要なもの

- Python 3
- PC にインストール済みのフォント `JFドットmilkjf16` (`config.py` の `FONT_FAMILY` で指定)
- 次のパッケージ

```text
python -m pip install -r requirements.txt
```

フォントファイルはこのフォルダには置きません。Windows に入っているフォントを名前で使います。

## フォルダ

- `img` : 元画像
- `list.csv` : 画像の有無、名前、URL
- `dist` : 出力。実行すると作られます

`config.py` のパスは、このフォルダを基準にした相対パスです。

## 入力

`list.csv` はヘッダなしの UTF-8 です。1行が次の3列です。

```text
true|false,名前,URL
```

1列目が `true` の行は、2列目のファイル名を `img` から読んで重ねます。`false` の行は元画像を読まず、2列目の名前で `dist` に保存します。拡張子がなければ `.png` を付けます。配置の指定はありません。文字は左寄せです。画像なしの URL は QR コードの左隣、下端揃えです。

```text
true,wwa_island02_town.png,https://wwawing.com/wing/island02
false,tellersdungeon,http://yuym.web.fc2.com/wwas/tellex/
```

## 実行

このフォルダで次を実行します。

```text
python batch_qr.py
```

出力は PNG で、`dist` に保存します。画像ありの行は入力と同じファイル名です。画像なしの行は2列目の名前です。同名のファイルが既にある行は上書きせずスキップします。作り直すときは、そのファイルを `dist` から消してから再実行します。

列の過不足、画像の有無の指定ミス、画像ありなのにファイルがない行はメッセージを出して次の行へ進みます。

## 配置

- URL 帯の1行の高さは 35px、背景色は `#cc66cc`、文字サイズは 32px です。折り返すと、行数ぶん高くなります。
- 帯の左右には 4px の余白を取り、その内側で文字単位に折り返します。
- 1行に収まるときは、帯の幅は文字幅に合わせます。画像ありは左下です。画像なしは QR の左隣で、下端を揃えます。
- 折り返したときは、帯の幅を折り返し幅いっぱいにします。画像ありは画像の幅、画像なしは `URL_WRAP_WIDTH` から QR の幅を引いた残りです。折り返した画像なしの出力幅は `URL_WRAP_WIDTH` になります。文字はどちらも左寄せで、短い行の文字がない部分も背景色で塗ります。
- 画像ありの QR コードは、帯のすぐ上、元画像の右端です。画像なしの QR コードは帯の右隣です。帯より上に QR がはみ出す部分の左は透明です。帯が QR より高いときは、QR の上で帯の右に空く部分も透明です。
- 画像ありの出力幅は元画像と同じです。QR や帯が画像の高さに収まらないときだけ、上へ透明な領域を足して切れないようにします。

## 設定

色、文字サイズ、帯の高さ、画像なしの折り返し幅、QR の大きさは `config.py` の定数で変えます。

QR の一辺のピクセル数は `(モジュール数 + QR_BORDER * 2) * QR_BOX_SIZE` です。URL が長いほどモジュール数が増え、QR も大きくなります。初期値の `QR_BOX_SIZE = 4` では、数十文字の URL でおよそ 120px になります。`QR_BORDER` を上げると、QR の周囲に白い余白が付きます。
